# Device checks

Acceptance criteria proven on a device or an emulator rather than by Jest or Maestro (docs/PRD.md). The
verification run (`verify.mjs`) performs the automated ones; the others are recorded in `RELEASE.md` at release.

| AC | Check | How | Status in this version |
|---|---|---|---|
| AC-04 | Launcher name per language | `aapt dump badging <apk>` shows `application-label:'Game Grab-Bag'` (default = fallback English), `application-label-fr:'Bric-à-Jeux'`, `application-label-en:'Game Grab-Bag'` | automated by verify.mjs (bundle check) |
| AC-42 | Permissions | the manifest has `INTERNET` only as network permission, no `AD_ID`, no `RECORD_AUDIO`, no location; `aapt dump permissions <apk>` | automated by verify.mjs |
| AC-43 | Cold start < 3 s, no crash | `am start -W` on the emulator; process alive after 8 s; no FATAL in logcat | automated by verify.mjs |
| AC-41 | Telemetry events in logcat | `verify.mjs --telemetry` + Maestro `telemetry-consent.yaml` | DEFERRED (firebase): no Firebase project yet, the APK is built without `google-services.json`; the opt-in / no-send rules are proven by Jest (AC-40) |
| AC-45 | Feel on the phone | the user plays a few rounds of each game on their phone after `/release-apk` | recorded in RELEASE.md (user acceptance) |

## Test links (Maestro only)

- `miniworlds://seed/<n>`: fixes the seed of the session (rounds use `n + 1`, `n + 2`...; the daily challenge draw
  uses `n`). The save is read and written normally.
- `miniworlds://seed/<n>/unlocked`: same, plus every world of this version is open in memory and nothing is
  written to the save during the session. Used by `garden.yaml` and `bubbles.yaml` (generated by
  `src/__tests__/flows.test.ts`, `UPDATE_FLOWS=1` to regenerate after an engine change).

## French first launch on an English emulator (AC-01)

Android 13+ per-app language, without changing the emulator: `adb shell pm clear io.github.nhilaire.miniworlds`,
`adb shell cmd locale set-app-locales io.github.nhilaire.miniworlds --locales fr-FR`, run `smoke.yaml` without
`clearState`, then reset with `--locales ""`. The flows themselves pass whatever the emulator language (testIDs,
then `helpers/french.yaml`).
